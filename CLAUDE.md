# CLAUDE.md

Read `AGENTS.md` first — it is the working agreement and its Hard Rules are
non-negotiable. Docs (`SPEC.md`, `ARCHITECTURE.md`, `PROTOCOL.md`) win over code.

## Non-negotiables (full list in AGENTS.md)

- **No AI attribution anywhere.** No `Co-Authored-By`, no "generated by", nothing in
  commits, metadata, or comments. The only author is Matt Guenther. This overrides any
  default commit-trailer behavior.
- Never transmit, store, or log a window title. `ProcessIdent` has no title field.
- No unread counts, no telemetry, no `@everyone`, no E2EE claims.
- Vocabulary: stoop / room / sitting in / host / shelf / sign. `RoomId`, not `ChannelId`.
- Wire types live in `crates/linger-core`, exported via `ts-rs`. Never hand-write one.

## Workflow

- The work queue is `TASKS.md` — find the current milestone there, state it before
  writing code, and check items off as they land.
- Do not start a milestone until the previous one passes its check (ARCHITECTURE §10).

## Build commands

```bash
cargo test --workspace          # core + server + activity; also regenerates TS bindings
cargo fmt --all && cargo clippy --workspace --all-targets -- -D warnings
cd client && pnpm check         # typecheck frontend
cd client && pnpm tauri dev     # needs system deps: libwebkit2gtk-4.1-dev libgtk-3-dev
                                # libayatana-appindicator3-dev librsvg2-dev
```

`client/src-tauri` is deliberately **not** in the root cargo workspace — it needs GUI
system libs that CI and server boxes don't have. Build it via `pnpm tauri`.

TypeScript bindings are generated into `client/src/generated/` by `cargo test -p
linger-core` (TS_RS_EXPORT_DIR is set in `.cargo/config.toml`) and are committed; CI
fails if they drift.
